First public Android release of Amaranto Feed.

- Reggina RSS news with article links and rotating stadium fallback images.
- Fixtures, results, and standings directly from LND, with an offline data cache.
- Optional background news checks and local notifications.
- Shared amaranto dark theme, light theme, and branded launch screens.
- Consistent team-logo tiles, with clearer official Vigor Lamezia and Trapani crests.
- A download button in the feed header when a newer GitHub APK release is available.

Download **amaranto-feed-1.0.0.apk** below and open it on your Android device.
Android may ask you to allow installation from the browser. Future public APK
releases will update this installation without resetting settings or cached data.

Chat remains a placeholder. iOS is not included in this release. Android controls
background scheduling and may defer the approximate 30-minute news checks.
