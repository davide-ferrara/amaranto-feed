Amaranto Feed 1.0.1 refreshes the launcher icon with a clean white background
and gives the native startup screen a neutral background that keeps the mark
readable in either system theme: white in light mode and charcoal in dark mode.

This release also includes the in-app GitHub update prompt. On Android, the
feed header offers the APK when a newer stable release is available.

Download **amaranto-feed-1.0.1.apk** below and open it on your Android device.
Android may ask you to allow installation from the browser. The APK is signed
with the same key as 1.0.0, so it can update that release in place.
